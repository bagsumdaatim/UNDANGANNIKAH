# ZULFA & GHOZI — Wedding Website

Versi ini memakai foto yang Anda upload sebagai aset utama.

## Cara menjalankan
Extract ZIP lalu buka `index.html`.

## Personalisasi tamu
`index.html?to=Nama%20Tamu`

Contoh:
`index.html?to=Bapak%20Ahmad%20dan%20Keluarga`

## Isi utama
- Opening cinematic
- Cerita pertemuan di Polres Aceh Timur
- Timeline hubungan
- Bagian dramatic storytelling
- Acara akad & resepsi
- Countdown
- Galeri
- RSVP
- Wedding gift
- Personalized guest URL
- Responsive HP/desktop

Tanggal dan lokasi contoh masih perlu diganti dengan data pernikahan sebenarnya.


## Musik
File musik berada di `assets/music/wedding.mp3`.
Musik mulai setelah tombol **Buka Undangan** ditekan karena browser HP biasanya memblokir autoplay sebelum interaksi pengguna.
Tombol musik berada di pojok kanan bawah untuk play/pause.
